# TorgLink landing

Jekyll landing for [Iskra.MAUI](https://github.com/IskraMessenger/Iskra.MAUI/tree/dev/0.1) (product name: **TorgLink**).

| Language | Overview | Quick Start | Known Issues | Releases |
|----------|----------|-------------|--------------|----------|
| English | `/torglink/` | `/torglink/quickstart/` | `/torglink/known-issues/` | `/torglink/releases/` |
| Russian | `/torglink/ru/` | `/torglink/ru/quickstart/` | `/torglink/ru/known-issues/` | `/torglink/ru/releases/` |
| German | `/torglink/de/` | `/torglink/de/quickstart/` | `/torglink/de/known-issues/` | `/torglink/de/releases/` |
| French | `/torglink/fr/` | `/torglink/fr/quickstart/` | `/torglink/fr/known-issues/` | `/torglink/fr/releases/` |
| Spanish | `/torglink/es/` | `/torglink/es/quickstart/` | `/torglink/es/known-issues/` | `/torglink/es/releases/` |
| Simplified Chinese | `/torglink/zh/` | `/torglink/zh/quickstart/` | `/torglink/zh/known-issues/` | `/torglink/zh/releases/` |

Legacy `/iskra/` paths redirect to the matching `/torglink/` URL.

Release notes live in `_data/releases.yml` (add new entries at the top).

Known issues live in `_data/known_issues.yml` (add new entries at the top).

The Simplified Chinese page shows a bilingual warning about possible translation inaccuracies.

Pages are marked `noindex`.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

# TorgLink landing (draft)

Jekyll landing for [Iskra.MAUI](https://github.com/IskraMessenger/Iskra.MAUI/tree/dev/0.1) (product name: **TorgLink**).

| Language | Overview | Releases |
|----------|----------|----------|
| English | `/iskra/` | `/iskra/releases/` |
| Russian | `/iskra/ru/` | `/iskra/ru/releases/` |
| German | `/iskra/de/` | `/iskra/de/releases/` |
| French | `/iskra/fr/` | `/iskra/fr/releases/` |
| Spanish | `/iskra/es/` | `/iskra/es/releases/` |
| Simplified Chinese | `/iskra/zh/` | `/iskra/zh/releases/` |

Release notes live in `_data/releases.yml` (add new entries at the top).

The Simplified Chinese page shows a bilingual warning about possible translation inaccuracies.

This is a draft, not a product launch. Pages are marked `noindex`.

Published URL paths still use `/iskra/` (folder + permalinks). Rename to `/torglink/` when you are ready to change public routes.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

# Iskra landing (draft)

Jekyll landing for [Iskra.MAUI](https://github.com/IskraMessenger/Iskra.MAUI/tree/dev/0.1).

| Language | Path |
|----------|------|
| English | `/iskra/` |
| Russian | `/iskra/ru/` |
| Spanish | `/iskra/es/` |
| Simplified Chinese | `/iskra/zh/` |

The Simplified Chinese page shows a bilingual warning about possible translation inaccuracies.

This is a draft, not a product launch. Pages are marked `noindex`.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```
